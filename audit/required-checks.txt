# Every line is a CRITICAL check: a release is only allowed when all of them PASS in one run of audit\run-audit.ps1.
# A check that did not report at all counts as FAILED ("NOT RUN"), so a check that crashes or is skipped cannot hide.
# Format:  ID | where it runs | what it proves
BUILD-OK              | script | the mod and the launcher build without errors, and the audited mod is the one installed for the run
LZ-ROUNDTRIP          | game   | the compressor gives back exactly what went in (edge cases and real plant data)
LZ-HOSTILE            | game   | garbage, absurd sizes and length bombs only cause ordinary errors: no crash, no giant allocation
GATE-ROUTING          | game   | network messages are routed by the rules: only the host's world is accepted, oversized data is dropped
SAVE-PATHS            | game   | every save goes to coop-saves and Steam Cloud saving is off
GUEST-ISOLATION       | game   | as a guest, saving (even forced) never changes my own save files
PLANT-SEND            | game   | a growing plant is announced, not more often than every 3 s, and its final state is sent
PLANT-SIZE            | game   | one plant update stays small (under 100 KB) and cheap to make (under 60 ms)
PLANT-CONVERGE        | game   | a copy that only has an older plant ends up identical to the sender's, islands counter included
PLANT-REBUILD         | game   | when updating in place fails, the fallback rebuild still gives the identical plant (fault injected)
PLANT-DEFER           | game   | while my walkster stands on a plant, a friend update waits and lands once I step off (no rebuild under the camera)
REMOTE-NO-GRAB       | game   | a remote player copy told to grab never grabs anything in my world (no pulling on my plant, no lock on my walkster)
CLONE-NO-JETPACK      | game   | a remote player copy has no jetpack of its own, so it cannot disturb my fuel meter
WATCHDOG              | game   | a frozen game is reported in the log after 5 s (and again when it recovers); a running game writes nothing
PLANT-THROTTLE        | game   | a big plant is re-sent less often than a small one (3 s up to 30 s), so a grown beanstalk does not flood the main thread and the network
STEAM-ENV             | game   | the mod puts the Steam app id in the environment first thing, so the game's own Steam check does not hand the launch to the regular game
PLANT-PART-STEER     | game   | a friend held-object packet never moves a plant part (the plant is synced by its own updates only)
PLANT-NOLEAK          | game   | sending plants does not pile up the game's after-load callbacks (they later crash on deleted branches)
PLANT-OWNER           | game   | a received plant is never echoed, a plant a friend is growing is not overwritten, sending resumes afterwards
ISLAND-ATTACH         | game   | an island a friend connected shows as connected on my side
ISLAND-COUNTER        | game   | connecting an island is announced once, a friend's raises my counter and HUD, nothing is echoed, silly values are refused
CRYSTAL-SYNC          | game   | a crystal I collect is announced, a friend's disappears here and counts for the team, a made-up one does nothing
MSG-FUZZ              | game   | hundreds of broken and hostile messages change nothing, escape nowhere and are never slow
UPDATE-OFFLINE-FAST   | exe    | a dead or hanging update server delays the start by seconds at most and touches nothing
UPDATE-BUTTON         | exe    | the home page's Check for updates button checks now (also when automatic checks are off), stages a newer mod, and reports an unreachable server
LAUNCH-PARENT         | exe    | a program the launcher starts under Steam has steam.exe as its parent, so the game is not sent to the regular game when the launcher was opened from Explorer
UPDATE-STAGED-APPLY   | exe    | a newer mod is downloaded first, installed at the next start, the old one is kept
UPDATE-TAMPER-REJECT  | exe    | a download that does not match its SHA-256 is never staged or installed
UPDATE-NO-DOWNGRADE   | exe    | the same or an older version changes nothing
UPDATE-BAD-MANIFEST   | exe    | broken manifests and non-https download addresses are ignored without a crash
UPDATE-STAGE-TAMPER   | exe    | a staged file changed after download, or not newer, is refused and removed
PATCH-CORRECT         | exe    | the patcher adds exactly one call to the mod at the start of SteamManager.Awake to the supported Steam build
INSTALL-PATCHED       | exe    | the installed game really calls the mod when it starts
GAME-STARTS-MODDED    | script | the modded game starts, loads the mod, reaches the world on its own and does not crash
NO-UNEXPECTED-ERRORS  | script | the mod log and the Unity log contain no errors or exceptions from the mod during the whole run
ORIGINAL-UNTOUCHED    | script | the real Steam save files and the original Grow Home assembly are exactly as before the run
AUDIT-RESTORED        | script | the test copy's saves, logs and settings are put back exactly as they were before the run
STARTUP-FAST          | game   | the start menu is reached quickly (the intro logo screens are skipped)
LAUNCH-VERIFIED       | script | the real launcher starts the co-op copy on this PC and confirms the mod loaded, within 60 s
LAUNCH-VERIFY         | exe    | the launcher tells apart: mod loaded, regular game started instead, nothing started, game closed again, mod missing
RUNNING-GAME          | exe    | a regular Grow Home that is already running is told apart from the co-op copy
BORROWER-DETECT       | exe    | a Steam account that only borrows the game (Family Sharing) is recognised, so it is started through Steam
STEAM-LAUNCH-OPTION   | exe    | Steam's launch option that makes Play start the co-op copy is edited safely: only that line, exact undo, damaged files refused, real settings files read
INSTALL-FAST          | exe    | the install links the big data files instead of copying (seconds, no extra disk), never links what the game or patcher writes, deleting the copy never touches the original

UPDATE-SIGNED         | exe    | only the author can update the mod: an update must carry a valid signature (not missing, not from another key, not reusable for another file, address or version), come from GitHub over https, not be redirected elsewhere and not be oversized
NET-SANITY            | game   | everything another player's PC sends is checked: pose packets with impossible numbers or cut off, bad visibility messages and log floods are refused without throwing
PLAYER-NAMES          | game   | players are shown by their Steam names (own name read from Steam), cleaned: nothing the game's font cannot draw, no markup, at most 16 letters, duplicates told apart, Player N until Steam has told us
CHAT                  | game   | in-game chat: messages are cleaned (plain text, 100 characters), shown under the sender's real connection name (nobody can speak as someone else), limited to 5 per 6 seconds per player, damaged ones refused, and mine is sent once
LAUNCH-DIRECT-FIRST   | exe    | every account, also one that only borrows the game, starts the co-op copy directly: no Steam restart and no Steam setting changed unless a direct start has failed (the old --via-steam option is ignored, and the audit launches with it to prove that)
ROOMS                 | game   | public rooms let everybody in, private rooms only players the host accepted, refused players never, unknown mode counts as private, hostile room data and room names are handled safely
MOUSE-FREE            | game   | while the code box / join window is open the mouse is shown and unlocked so JOIN and CANCEL can be clicked, and the game gets it back afterwards
GHOST-LEFT            | game   | a player who closed the game (no signal for 6 s) is taken out of the other players worlds, not earlier
TELEPORTER-SYNC       | game   | switching a teleporter on unlocks it for every player: mine is announced once, a friend's unlocks it here and is not sent back, broken messages are refused
ROOM-TALK            | game   | a player my room does not let in (or who left it) is heard by nobody; without a room the configured players are heard
ROOM-HOST            | game   | the host stays the player I joined, even after Steam hands the room to someone else; a later joiner is never taken for host

CLOUD-NAMES          | game   | a Steam Cloud file name can never take a save outside the save folder
SETTINGS             | exe    | the launcher settings: on-screen display, name tags, chat log and world sharing are plain files that switch both ways, and the room setting cycles public, listed-you-accept, private

COOP-MENU            | game   | the pause menu has a CO-OP line (right under Settings) opening a real game menu made from the game's own Settings menu: right lines for every state, labelled, inside the panel, first line selected, display switch both ways, Back/cancel return to pause, Join leaves the menus and opens the join window
PARTY                | game   | the party rules and lines: members follow the leader in only when the leader starts a game they have not seen started, once let in; the member list (leader first, ready, waiting), friends sorted and paged; the right lines in every party state, at most 7 that do something, BACK last

WORLD-PARTS          | game   | a grown world (bigger than one Steam message) goes in packed parts and comes back exactly; damaged or foreign parts are refused
LEADER-SAVE          | game   | only the leader's save is real: the leader answers from the start screen, a guest never starts a world of its own or sends its own world, the leader ignores changes from players not in its world, and a copy of the leader's save is kept
